# ScanVault

ScanVault is a free Android document scanner that keeps every page encrypted on your phone: automatic edge finding, searchable PDFs, signing and form filling, true black-out, Smart Erase, timestamp photos, CountCam, passport photos and an ID Vault. No adverts, no account, no cloud.

Website: https://customgpter.github.io/scanvault/
